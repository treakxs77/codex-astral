# Le Codex Astral et la Forge de Tyrie

Compagnon personnel pour Guild Wars 2 : consultation du compte, préparation des aventures et installation des modules depuis la Forge de Tyrie.

## Installation sur Windows 10 ou 11, 64 bits

Télécharger le fichier `Installation-Codex-Astral-…exe` dans la [dernière version publiée](https://github.com/treakxs77/codex-astral/releases/latest), puis le lancer. Les comptes et réglages du Codex sont conservés séparément du programme.

Le Codex recherche les nouvelles versions à chaque ouverture lorsqu’une connexion Internet est disponible. Une fenêtre propose leur installation. Une recherche manuelle est aussi disponible dans **Mon espace → Rechercher une mise à jour**.

Les annonces de mise à jour sont signées et les fichiers téléchargés sont vérifiés avant exécution.

Ce dépôt contient les fichiers de distribution et les notes de version. Les outils de développement et les fichiers de signature privés ne sont pas publiés ici.
